บทที่ 3

กราฟฟังก์ชันตรีโกณ

ทุกอย่างที่เกิดซ้ำเป็นจังหวะ — คลื่นเสียง ไฟฟ้ากระแสสลับ น้ำขึ้นน้ำลง การเต้นของหัวใจ ฤดูกาล — อธิบายได้ด้วยกราฟไซน์ที่ถูกยืด บีบ และเลื่อน บทนี้สอนวิธีควบคุมทั้งสามอย่างนั้น

3.1 กราฟพื้นฐานของ sin และ cos

จากบทที่แล้ว เมื่อจุดวิ่งรอบวงกลมหนึ่งหน่วยครบหนึ่งรอบ ค่า y ของมันจะขึ้นจาก 0 ไป 1 ลงมา −1 แล้วกลับมา 0 เขียนค่านั้นเทียบกับมุมจะได้กราฟ $y=\sin x$ ซึ่งซ้ำตัวเองทุก ๆ $2\pi$

สมบัติ$y=\sin x$$y=\cos x$$y=\tan x$
โดเมนจำนวนจริงทุกจำนวนจำนวนจริงทุกจำนวนทุกจำนวนยกเว้น $\tfrac{\pi}{2}+k\pi$
เรนจ์$[-1,\,1]$$[-1,\,1]$จำนวนจริงทุกจำนวน
คาบ$2\pi$$2\pi$$\pi$
ตัดแกน y ที่010
สมมาตรฟังก์ชันคี่ $\sin(-x)=-\sin x$ฟังก์ชันคู่ $\cos(-x)=\cos x$ฟังก์ชันคี่
cos คือ sin ที่ถูกเลื่อน

กราฟทั้งสองรูปร่างเหมือนกันเป๊ะ ต่างกันแค่ตำแหน่งเริ่มต้น $$\cos x = \sin\!\left(x+\frac{\pi}{2}\right)$$ นี่คือเหตุผลที่เรามักเรียกรวม ๆ ว่า “คลื่นรูปไซน์” (sinusoid) ไม่ว่าจะเขียนด้วย sin หรือ cos

3.2 การแปลงกราฟด้วย A, B, C, D

กราฟไซน์ทุกกราฟในโลกนี้เขียนได้ในรูปเดียวกัน สี่ตัวแปรควบคุมสี่เรื่องที่ต่างกันโดยสิ้นเชิง ลองปรับทีละตัวในภาพด้านล่าง แล้วทายก่อนว่าจะเกิดอะไรขึ้น

$$y = A\,\sin\bigl(B(x - C)\bigr) + D$$
ตัวแปรชื่อควบคุมอะไรสูตร
$A$แอมพลิจูด (amplitude)ความสูงจากเส้นกึ่งกลางถึงยอด ถ้า $A<0$ กราฟพลิกกลับหัวแอมพลิจูด $=|A|$
$B$ตัวคูณเชิงมุมความถี่ — ยิ่งมากยิ่งบีบแคบ ลูกคลื่นถี่ขึ้นคาบ $=\dfrac{2\pi}{|B|}$
$C$การเลื่อนเฟส (phase shift)เลื่อนซ้าย–ขวา ถ้า $C>0$ เลื่อนไปทางขวาเลื่อนไป $C$ หน่วย
$D$การเลื่อนแนวตั้งยกทั้งกราฟขึ้นลงเส้นกึ่งกลาง $y=D$
กับดักที่ทำให้เสียคะแนนบ่อยที่สุดในบทนี้

ตำราส่วนใหญ่เขียนสมการเป็น $y=A\sin(Bx - C)+D$ ซึ่ง C ในรูปนั้นไม่ใช่ระยะเลื่อน ต้องดึง B ออกมาก่อนเสมอ

$$A\sin(Bx-C)+D = A\sin\!\Bigl(B\bigl(x-\tfrac{C}{B}\bigr)\Bigr)+D \quad\Rightarrow\quad \text{เลื่อนไป } \frac{C}{B} \text{ หน่วย}$$

เช่น $y=\sin(2x-\pi)$ ไม่ได้เลื่อนไป π แต่เลื่อนไป $\pi/2$ เท่านั้น

โจทย์ตัวอย่าง 1 — จากสมการไปหาสมบัติ

จงหาแอมพลิจูด คาบ การเลื่อนเฟส เส้นกึ่งกลาง และเรนจ์ ของ $y = -3\cos(4x + \pi) + 2$

  1. จัดรูปให้อยู่ในแบบมาตรฐานโดยดึง B ออก $$y=-3\cos\!\bigl(4(x+\tfrac{\pi}{4})\bigr)+2 = -3\cos\!\bigl(4(x-(-\tfrac{\pi}{4}))\bigr)+2$$
  2. อ่านค่า: $A=-3$, $B=4$, $C=-\dfrac{\pi}{4}$, $D=2$
  3. แอมพลิจูด $=|-3|=3$ (เครื่องหมายลบไม่ทำให้แอมพลิจูดติดลบ แต่ทำให้กราฟพลิกกลับหัว)
  4. คาบ $=\dfrac{2\pi}{4}=\dfrac{\pi}{2}$
  5. เลื่อนเฟสไป $-\dfrac{\pi}{4}$ แปลว่าเลื่อนไปทาง ซ้าย $\dfrac{\pi}{4}$ หน่วย
  6. เส้นกึ่งกลาง $y=2$ ดังนั้นค่าสูงสุด $=2+3=5$ และค่าต่ำสุด $=2-3=-1$
ตอบ แอมพลิจูด 3 · คาบ $\pi/2$ · เลื่อนซ้าย $\pi/4$ · เส้นกึ่งกลาง $y=2$ · เรนจ์ $[-1,\,5]$

โจทย์ตัวอย่าง 2 — จากกราฟไปหาสมการ

กราฟรูปไซน์รูปหนึ่งมีค่าสูงสุด 7 ค่าต่ำสุด 1 มีคาบเท่ากับ 8 และมีค่าสูงสุดครั้งแรกที่ $x=2$ จงเขียนสมการของกราฟนี้

  1. หาเส้นกึ่งกลางจากค่ากลางของสูงสุดกับต่ำสุด $$D=\frac{7+1}{2}=4$$
  2. หาแอมพลิจูดจากครึ่งหนึ่งของผลต่าง $$A=\frac{7-1}{2}=3$$
  3. หา B จากคาบ $\dfrac{2\pi}{B}=8 \Rightarrow B=\dfrac{\pi}{4}$
  4. เลือกใช้ cos จะง่ายกว่า เพราะ cos มีค่าสูงสุดที่จุดเริ่มต้นพอดี — ต้องการให้ยอดอยู่ที่ $x=2$ จึงเลื่อนขวา 2 หน่วย ได้ $C=2$
  5. ประกอบร่าง $$y = 3\cos\!\left(\frac{\pi}{4}(x-2)\right)+4$$
  6. ตรวจ: แทน $x=2$ ได้ $3\cos 0+4=7$ ✓ และแทน $x=6$ (ครึ่งคาบถัดไป) ได้ $3\cos\pi+4=1$ ✓
ตอบ $y = 3\cos\left(\dfrac{\pi}{4}(x-2)\right)+4$ (เขียนด้วย sin ก็ได้ เป็น $y=3\sin\left(\dfrac{\pi}{4}x\right)+4$)

3.3 กราฟของ tan

กราฟ tan หน้าตาไม่เหมือนสองตัวแรกเลย เพราะ $\tan x = \dfrac{\sin x}{\cos x}$ จึงพุ่งไปอนันต์ทุกครั้งที่ $\cos x = 0$ ลองเลื่อนมุมในภาพด้านล่างเข้าใกล้ 90° แล้วดูว่าเกิดอะไรขึ้นกับความยาวของเส้นสีเขียว

สมบัติสำคัญของ tan
  • คาบเท่ากับ $\pi$ ไม่ใช่ $2\pi$ — เพราะมุมที่ต่างกัน 180° อยู่บนเส้นตรงเดียวกัน ความชันจึงเท่ากัน
  • มีเส้นกำกับ (asymptote) ที่ $x=\dfrac{\pi}{2}+k\pi$ ซึ่งเป็นตำแหน่งที่ $\cos x=0$
  • เพิ่มขึ้นเสมอในแต่ละช่วงระหว่างเส้นกำกับ และมีเรนจ์เป็นจำนวนจริงทั้งหมด
  • ความหมายเชิงเรขาคณิต: $\tan\theta$ คือ ความชันของเส้นรัศมี ที่ลากจากจุดกำเนิดไปยังจุดบนวงกลม

3.4 การประยุกต์กับปรากฏการณ์เป็นคาบ

ขั้นตอนการสร้างแบบจำลองจากสถานการณ์จริงมีสี่ขั้นเสมอ และตรงกับ D, A, B, C พอดี

  1. หาเส้นกึ่งกลาง D = ค่าเฉลี่ยของค่าสูงสุดกับต่ำสุด
  2. หาแอมพลิจูด A = ครึ่งหนึ่งของผลต่างระหว่างสูงสุดกับต่ำสุด
  3. หา B จากคาบ = เวลาที่ใช้ครบหนึ่งรอบ แล้วใช้ $B=2\pi/\text{คาบ}$
  4. หา C จากจุดอ้างอิง = เวลาที่เกิดค่าสูงสุด (ถ้าใช้ cos) หรือเวลาที่ผ่านเส้นกึ่งกลางขาขึ้น (ถ้าใช้ sin)

โจทย์ตัวอย่าง 3 — ชิงช้าสวรรค์

ชิงช้าสวรรค์รัศมี 20 เมตร จุดต่ำสุดของกระเช้าอยู่สูงจากพื้น 2 เมตร หมุนครบรอบใน 4 นาที ผู้โดยสารขึ้นที่จุดต่ำสุดตอนเวลา $t=0$ จงเขียนสมการความสูง $h(t)$ และหาความสูงที่เวลา 3 นาที

  1. ค่าต่ำสุด = 2 ม. และค่าสูงสุด = 2 + 2(20) = 42 ม.
  2. เส้นกึ่งกลาง $D=\dfrac{42+2}{2}=22$ และแอมพลิจูด $A=\dfrac{42-2}{2}=20$ (เท่ากับรัศมีพอดี ตามที่ควรเป็น)
  3. คาบ 4 นาที ดังนั้น $B=\dfrac{2\pi}{4}=\dfrac{\pi}{2}$
  4. ที่ $t=0$ อยู่ ต่ำสุด — ฟังก์ชันที่เริ่มจากต่ำสุดคือ $-\cos$ พอดี จึงเขียนได้ทันทีโดยไม่ต้องเลื่อนเฟส $$h(t) = -20\cos\!\left(\frac{\pi}{2}t\right)+22$$
  5. แทน $t=3$: $\;h(3)=-20\cos\left(\dfrac{3\pi}{2}\right)+22=-20(0)+22=22$
ตอบ $h(t)=-20\cos\left(\dfrac{\pi}{2}t\right)+22$ และที่เวลา 3 นาที ผู้โดยสารอยู่สูง 22 เมตร (ระดับกึ่งกลางพอดี กำลังลง)
เคล็ดลับ: เลือก sin หรือ cos ให้ถูก
  • เริ่มที่ ค่าสูงสุด → ใช้ $+\cos$
  • เริ่มที่ ค่าต่ำสุด → ใช้ $-\cos$
  • เริ่มที่ เส้นกึ่งกลางแล้วขึ้น → ใช้ $+\sin$
  • เริ่มที่ เส้นกึ่งกลางแล้วลง → ใช้ $-\sin$

เลือกให้ตรงกับจุดเริ่มต้น จะไม่ต้องคำนวณการเลื่อนเฟสเลย

เช็กลิสต์ก่อนขึ้นบทถัดไป
  • ระบุแอมพลิจูด คาบ การเลื่อนเฟส และเส้นกึ่งกลาง จากสมการใด ๆ ได้ พร้อมจัดรูปดึง B ออกก่อนเสมอ
  • เขียนสมการจากกราฟหรือจากสถานการณ์จริงได้
  • อธิบายได้ว่าทำไมกราฟ tan มีคาบ π และมีเส้นกำกับตรงไหน
  • วาดกราฟคร่าว ๆ ด้วยมือได้ โดยหาจุดสำคัญห้าจุดในหนึ่งคาบ
