# ตรีโกณมิติเห็นภาพ · Trigonometry Visual

สื่อการเรียนรู้ตรีโกณมิติแบบโต้ตอบสำหรับนักเรียนระดับมัธยมปลาย
ทุกภาพประกอบปรับเปลี่ยนได้เอง — ลากจุด เลื่อนแถบ กดเล่นแอนิเมชัน แล้วดูตัวเลขเปลี่ยนตามทันที

**เว็บไซต์:** https://thtpk.github.io/Trigonometry/

---

## เนื้อหา

| บท | หัวข้อ | ภาพประกอบเชิงโต้ตอบ |
|----|--------|---------------------|
| 1 | สามเหลี่ยมมุมฉาก | สามเหลี่ยมคล้าย · นิยาม sin/cos/tan (ลากได้) · แผนภาพช่วยจำหกฟังก์ชัน · ที่มาของมุมพิเศษ · แผนภาพช่วยจำกับมุม 30/45/60 · มุมเงย |
| 2 | วงกลมหนึ่งหน่วย | วงกลมหนึ่งหน่วย (ลากได้) · เรเดียน · คลี่วงกลมเป็นกราฟ |
| 3 | กราฟฟังก์ชันตรีโกณ | เครื่องสร้างคลื่น A/B/C/D · กราฟ tan กับเส้นกำกับ · น้ำขึ้นน้ำลง |
| 4 | เอกลักษณ์ตรีโกณ | พีทาโกรัสบนวงกลม · พิสูจน์ sin(A+B) ด้วยรูป · ตรวจเอกลักษณ์ด้วยกราฟ · รวมคลื่น R sin(x+α) |
| 5 | สมการตรีโกณ | นับคำตอบจากจุดตัด · สมการมุมหลายเท่า · กับดักคำตอบหาย · a sin x + b cos x = c |
| 6 | กฎไซน์–โคไซน์ | สามเหลี่ยมลากได้กับวงกลมล้อมรอบ · กรณีกำกวม SSA · กฎโคไซน์เทียบพีทาโกรัส · พื้นที่และเฮรอน |
| 7 | ฟังก์ชันผกผัน | กราฟผกผันสะท้อนข้าม y = x · กับดัก arcsin(sin x) · ฟังก์ชันประกอบด้วยสามเหลี่ยม |
| 8 | พิกัดเชิงขั้ว·เชิงซ้อน | ลากจุดในพิกัดเชิงขั้ว · คาร์ดิออยด์และกุหลาบ · คูณ = หมุน · รากที่ n |
| — | สรุปสูตร | ทุกสูตรในหน้าเดียว จัดกลุ่มและพิมพ์ลง A4 ได้ |

แต่ละบทประกอบด้วย: คำอธิบายแนวคิด → ภาพให้ทดลองเอง → กล่องสรุปสูตร →
โจทย์ตัวอย่างแสดงทุกขั้นตอน → กล่องเตือนข้อผิดพลาดที่พบบ่อย → เช็กลิสต์ก่อนขึ้นบทถัดไป

## หลักการออกแบบ

- **สีมีความหมายคงที่ทั้งเว็บ** — น้ำเงิน = sin, ส้ม = cos, เขียว = tan, ม่วง = ด้านตรงข้ามมุมฉาก/รัศมี
- **ทุกสูตรมีที่มา** ไม่มีสูตรไหนโผล่มาลอย ๆ
- **ใช้ได้ทั้งเมาส์และนิ้ว** ภาพทุกตัวรองรับการลากบนหน้าจอสัมผัส

## เทคโนโลยี

HTML + CSS + JavaScript ล้วน ไม่มี framework ไม่มี build step ไม่มี dependency ที่ต้องติดตั้ง

- ภาพประกอบทั้งหมดวาดด้วย Canvas 2D API โดยตรง
- สูตรคณิตศาสตร์เรนเดอร์ด้วย [KaTeX](https://katex.org/) (โหลดจาก CDN)
- ฟอนต์ Sarabun และ IBM Plex Sans Thai จาก Google Fonts

## โครงสร้างไฟล์

```
index.html          หน้าแรก · สารบัญ · เส้นทางการเรียน
ch1.html … ch8.html เนื้อหาแต่ละบท
formulas.html      หน้าสรุปสูตรพร้อมพิมพ์
assets/css/style.css
assets/js/viz.js     ระบบพิกัดและเครื่องมือวาดบน canvas
assets/js/widgets.js นิยามภาพประกอบทั้ง 32 ตัว
assets/js/site.js    แถบบน สารบัญข้าง และการเลื่อนตามหัวข้อ
```

การเพิ่มภาพประกอบใหม่ทำได้โดยวาง `<div class="widget" id="w-ชื่อ"></div>` ในหน้า HTML
แล้วประกาศ `TV.widget('#w-ชื่อ', { ... })` ใน `widgets.js` — ตัว widget จะสร้างหัวเรื่อง canvas
แถบค่า ตัวควบคุม และคำใบ้ให้เองทั้งหมด

## เปิดดูในเครื่อง

ต้องเปิดผ่าน HTTP server (เปิดไฟล์ตรง ๆ ด้วย `file://` จะโหลดสคริปต์ไม่ครบ)

```bash
python -m http.server 8712
```

แล้วเปิด http://localhost:8712

## การเผยแพร่บน GitHub Pages

เว็บนี้เป็น static site ที่ root ของ repo จึงเปิด Pages ได้โดยตรง

1. ไปที่ **Settings → Pages**
2. **Source** เลือก *Deploy from a branch*
3. **Branch** เลือก `main` และโฟลเดอร์ `/ (root)` แล้วกด Save

รอสักครู่ เว็บจะขึ้นที่ `https://<username>.github.io/Trigonometry/`
